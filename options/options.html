MarkDownload 设置

对某个选项点一下即自动保存；所有设置会自动同步到你登录的 Chrome 账号。带 “变量” 的输入框支持下面的替换语法，可自动插入文章信息。

📁 保存位置

受浏览器安全限制，扩展只能静默保存到系统「下载」目录（~/Downloads）内的子文件夹， 不能直接写入任意磁盘路径。两种选择：
  • ① 在下方一键选定一个「下载」内的子文件夹，以后每次都存到那里（无需再选）；
  • ② 勾选「下载前询问位置」，每次用系统“另存为”对话框选任意目录（会记住上次的位置）。

🏷️ 标题与模板

决定下载文件的名称（不含路径，非法字符会被自动去掉）。默认 {pageTitle} 用网页标题。 建议改成 {date:YYYY-MM-DD} - {pageTitle} 以便排序，或 {title} 用正文提取的文章标题。

🧩 变量参考（用于标题 / 模板 / 文件夹）

文本变量

标题、front/back matter、文件夹、图片前缀中都能用。并非每个网页都提供全部字段。

  • {title} — 文章标题（由正文内容提炼）
  • {pageTitle} — 网页 <title> 标题
  • {length} — 文章字数
  • {excerpt} — 文章摘要/导语
  • {byline} — 作者信息
  • {dir} — 文字方向
  • {keywords} — 网页关键词（如有，默认逗号分隔）
  • {keywords:SEP} — 用 SEP 分隔关键词，如 {keywords: } 用空格
  • {date:FORMAT} — 当前时间，FORMAT 用 Moment 格式， 如 {date:YYYY-MM-DD}。

网页链接变量（文章的 URL）

  • {baseURI} — 文章完整地址
  • {origin} — 协议+域名+端口
  • {host} — 域名(:端口)
  • {hostname} — 纯域名（最常用于按站分文件夹）
  • {port} — 端口
  • {protocol} — 协议，如 https:
  • {pathname} — 路径部分（不含查询串/锚点）
  • {search} — 查询串（含 ?）
  • {hash} — 锚点（含 #）
  • 任何 meta 标签也可用，如 {og:image}

大小写变换（不能用于 date / keywords）

  • {var:pascal} — PascalCase（每个单词首字母大写）
  • {var:camel} — camelCase（除首个单词外首字母大写）
  • {var:kebab} — kebab-case（小写、短横线连接）
  • {var:snake} — snake_case（小写、下划线连接）
显示在输出文件最上方。默认带 --- YAML 风格头，含创建时间、标签、来源链接、作者、摘要等。
显示在输出文件最末尾，常用于加版权声明、链接等。留空则不追加。
标题转文件名时会去掉这些字符。系统本身已强制去掉 /\?<>\:*|"， 这里再加一层你自己的过滤。一般保持默认即可。

🖼️ 图片

🔗 Obsidian 集成
要把剪藏内容直接发进 Obsidian，需要先在 Obsidian 里装一个社区插件：Advanced URI。 没装的话右键“发送到 Obsidian”会没反应。安装：
  1. 打开 Obsidian → 设置（左下角齿轮）→ 第三方插件 → 关闭「安全模式」
  2. 点 浏览，搜索 Advanced URI → 安装 → 启用
  3. 回到本页勾选下面“启用 Obsidian 集成”
插件文档：Obsidian Advanced URI
要写入的 Obsidian 库名称（库文件夹名）。留空则不指定 vault，Obsidian 会自动选择当前打开的库。 检测到你本机的库名是 OBSIdian，一般照抄即可。
剪藏文件存放的库内文件夹（不存在会自动创建）。默认 剪藏/；想换位置直接改这里，如 Clippers/。
